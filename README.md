# Lucky Dangle

A small devotional desktop charm that hangs from the top edge of your
Windows screen, with two selectable themes: **Murugan** (Vel charm) and
**Vinayagar** (Ganesha charm).

See the setup walkthrough provided alongside this project for full
step-by-step instructions. Quick reference:

```bash
npm install
npm start          # run in development
npm run dist        # build a Windows .exe installer (run on Windows)
```

Right-click the dangle (or its tray icon) to change deity, toggle
swinging, pin/unpin always-on-top, enable launch at startup, or exit.
